# NIST GAMS problem classification (read from https://gams.nist.gov/cgi-bin/serve.cgi)

Top level: A Arithmetic, error analysis; B Number theory; C Elementary and special functions; D Linear Algebra;
E Interpolation; F Solution of nonlinear equations; G Optimization; H Differentiation, integration;
I Differential and integral equations; J Integral transforms; K Approximation; L Statistics, probability;
M Simulation, stochastic modeling; N Data handling; O Symbolic computation; P Computational geometry;
Q Graphics; R Service routines; S Software development tools; Z Other

D: D1 Elementary vector and matrix operations; D2 Solution of systems of linear equations (including inversion, LU and related decompositions); D3 Determinants;
D4 Eigenvalues, eigenvectors; D5 QR decomposition, Gram-Schmidt orthogonalization; D6 Singular value decomposition; D7 Update matrix decompositions;
D8 Other matrix equations (e.g., AX+XB=C); D9 Singular, overdetermined or underdetermined systems of linear equations, generalized inverses
G: G1 Unconstrained; G2 Constrained; G3 Optimal control; G4 Service routines
G2: G2a Linear programming; G2b Transportation and assignments problem; G2c Integer programming; G2d Network;
G2e Quadratic programming; G2f Geometric programming; G2g Dynamic programming; G2h General nonlinear programming;
G2i Global solution to nonconvex problems
H: H1 Numerical differentiation; H2 Quadrature (numerical evaluation of definite integrals)
I: I1 Ordinary differential equations (ODE's) (I1a Initial value problems; I1b Multipoint boundary value problems);
I2 Partial differential equations; I3 Integral equations
J: J1 Trigonometric transforms including fast Fourier transforms; J2 Convolutions; J3 Laplace transforms; J4 Hilbert transforms
K: K1 Least squares (L-2) approximation; K2 Minimax (L-infinity) approximation; K3 Least absolute value (L-1) approximation; K4 Other analytic approximations (e.g., Taylor polynomial, Pade); K5 Smoothing
L: L1 Data summarization; L2 Data manipulation; L3 Elementary statistical graphics; L4 Elementary data analysis;
L5 Function evaluation; L6 Random number generation; L7 Analysis of variance (including analysis of covariance); L8 Regression; L9 Categorical data analysis;
L10 Time series analysis; L11 Correlation analysis; L12 Discriminant analysis; L13 Covariance structure models;
L14 Cluster analysis; L15 Life testing, survival analysis; L16 Multidimensional scaling; L17 Statistical data sets
Not fetched: subclasses of E, F, M, O.
